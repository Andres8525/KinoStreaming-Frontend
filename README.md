# Kino Streaming — Frontend

Angular web app for **Kino**, a streaming platform for independent creators.

The application lives in [`visual_Stream/`](visual_Stream/). See [`visual_Stream/README.md`](visual_Stream/README.md) for requirements, scripts, environments and the Vercel deployment guide.

- Backend API: [KinoStreaming-Backend](https://github.com/Andres8525/KinoStreaming-Backend) (Spring Boot on Render, PostgreSQL on Supabase)
- When deploying on Vercel, set **Root Directory** to `visual_Stream`.
